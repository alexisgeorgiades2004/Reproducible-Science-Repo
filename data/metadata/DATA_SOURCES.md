*Defining T Cell States Associated with Response to Checkpoint Immunotherapy in Melanoma.*
**Cell** 175(4):998–1013.e20, 1 November 2018.
DOI [10.1016/j.cell.2018.10.038](https://doi.org/10.1016/j.cell.2018.10.038) · PMID 30388456.

**Accession.** NCBI GEO Series [GSE120575](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE120575)
(public 5 October 2018; *Homo sapiens*; expression profiling by high-throughput sequencing).
Series summary: 16,291 immune cells from 48 tumour samples of melanoma patients treated with
checkpoint inhibitors.

**Base URL.** `https://ftp.ncbi.nlm.nih.gov/geo/series/GSE120nnn/GSE120575/`

**Downloaded.** 29 September 2026 (local file timestamps 22:52).

**Assay.** Plate-based Smart-seq2, one cell per well, CD45+ sorted tumour-infiltrating immune
cells. Values in the matrix are **log2(TPM+1)**, not linear TPM, despite the filename — see the
note below.

### Raw sequencing data (not available here)

Raw reads are **not** in GEO. They are deposited in dbGaP under accession `phs001680.v1.p1`
under controlled access, so nothing upstream of transcript quantification is reproducible from
this repository. The analysis begins from the processed expression matrix.

### Known quirks of these files

- The expression matrix has **two header rows** (cell identifier, then sample label), both
  offset by a leading empty field, and **a trailing tab on every data row** — so data rows
  split into one more field than the headers. Reading it with default `read_csv` settings is
  wrong in two separate ways.
- The filename says `TPM`; the values are `log2(TPM+1)`. Verified by un-logging with `2**x - 1`
  and checking that per-cell sums land on 1e6.
- `GSE120575_patient_ID_single_cells.txt.gz` is a filled-in GEO submission spreadsheet: the real
  column header is on line 19, not line 1.
- `soft/GSE120575_family.soft.gz` carries the per-GSM response and therapy labels but is
  **regenerated by GEO on request**, so its checksum drifts between downloads and is deliberately
  not pinned here. It is not used by this analysis; response labels come from the per-cell
  annotation file instead.
